The aim of this course

1. HTML (HyperText Markup Language)

  • The Role: HTML is the standard markup language used to create the structure and content of a webpage. Think of it as the skeleton of a house.

  • How it works: It uses a system of tags and elements (such as headings, paragraphs, links, images, and lists) to tell the web browser how to display text and media.

2. CSS (Cascading Style Sheets)

  • The Role: CSS is the style sheet language used to describe the presentation, design, and layout of a webpage written in HTML. Think of CSS as the paint, interior design, and clothing of the house.

  • How it works: It controls colors, fonts, spacing, positioning, and responsive design .
